# Start here

1. Extract the ZIP.
2. Open a terminal inside the rundrdach folder.
3. Run `npm ci`.
4. Copy `.env.example` to `.env.local`.
5. Run `npm run dev` and open http://localhost:3000.

Business information: `src/config/site.ts`.
German service texts: `src/data/services.ts`.
Real project photos: `public/images/` and `src/data/projects.ts`.
Colors and layout: `src/app/globals.css`.

Read README.md for Vercel, SEO, the email form and Google tracking setup.
